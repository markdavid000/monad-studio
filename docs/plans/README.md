# Plans

Implementation plans for work larger than a small fix, written after the ADRs are approved and before code. Name them `<YYYY-MM-DD>-<topic>-plan.md`.

A plan covers:

1. **Scope:** the issue and the approved ADRs it implements.
2. **Files:** what will be added, changed and removed, by layer.
3. **Interfaces:** route handlers, component props, hook return types, domain types.
4. **State:** which hook manages what, and the status each async action goes through.
5. **Wording:** where user-facing strings live.
6. **Tests:** what each test proves, including loading, empty and error states.
7. **UI:** a sketch of each state.
8. **Removal:** what this replaces and the packages that go with it.
