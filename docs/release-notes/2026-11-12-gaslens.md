# GasLens reviews gas and rewrites the contract

"Optimise gas" in the workspace now opens GasLens. It lists gas waste ranked by impact, each with an estimated saving per call, deployment or loop iteration, and shows the rewritten contract as a diff against yours. A second AI pass then compares the rewrite with your contract and flags any function that may behave differently, marking its lines in the diff. You can copy the rewrite; GasLens never swaps it into the workspace for you, and the page tells you to read every change and run MonGuard before deploying.

## Changes

- `features/gaslens`: reply schema and mapper (sorted by impact then saving, ids, whole number estimates, lines clamped, fences stripped), prompt with numbered lines and explicit rules against changing behaviour, the public interface or caching mapping values across writes, `POST /api/gaslens/analyze` on the shared AI core, `/studio/gaslens` with idle, loading, diff, source, applied, out of date, nothing to optimise, too large, rate limited and error states.
- Behaviour check (`features/gaslens/server/check.ts`): runs only when the rewrite differs, sends both contracts with line numbers, returns `clear`, `flagged` (risks with rewrite line numbers, marked in the diff and focused first) or `unavailable` when the second call fails, in which case the review is still shown with a warning that nothing was checked.
- Line diff (`features/gaslens/lib/diff.ts`): common prefix and suffix trimmed, LCS on the rest, removals before additions, trailing whitespace ignored.
- Shared now that two tools use them: `components/ui/code-view.tsx` (numbered lines with highlights and diff colours), `components/ui/ai-error-state.tsx`, `hooks/use-copy.ts`, `hooks/use-line-scroll.ts`, `lib/copy.ts` (AI note, error messages, line ranges, counts), `lib/code-text.ts`.
- The AI limit message now says it covers every studio tool, since MonGuard and GasLens share it.
- Groq calls set `max_completion_tokens` (16,384 by default, 40,000 for GasLens) so long rewrites are not cut off.

## Removed

- "Use in workspace": a rewrite is never applied in one click.
- MonGuard's own copies of the code view, error state, copy hook, line scroll hook and line range text.

## Verification

- Tests: diff (unchanged, added, removed, replaced, whitespace, 400 lines under 200 ms), mapper and input limits, the route (success, bad JSON, oversized, 429, schema mismatch, non JSON reply, Groq down), the page in every state, shared helpers.
- Live: about 15 GasLens runs on the three examples against Groq, 4 to 9 seconds each. Early prompts dropped public getters and cached a sender balance across a transfer loop; the final prompt keeps getters, but the balance caching bug still appeared in some GasHeavy runs.
- Behaviour check, three live GasHeavy runs (11 to 26 seconds with both calls): two rewrites cached the sender balance across the transfer loop and the check flagged `batchTransfer` with the self transfer case both times; the third rewrite ignored extra recipients when the arrays differ in length, and the check flagged that too.
- Real review from the page in headless Chrome at 1440px and 600px; flagged state checked in light and dark.
