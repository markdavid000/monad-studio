# Connect a wallet in the studio

The studio header now has a Connect wallet button. It opens the standard wallet picker (MetaMask, Rainbow, Coinbase Wallet and any WalletConnect wallet), asks to switch to Monad testnet when the wallet is on another network, and shows the network and address once connected. Nothing in the studio requires a wallet yet; deploying will.

## Changes

- `features/wallet`: wagmi 2 and RainbowKit 2 configured for Monad testnet only, cookie storage for server rendering, a RainbowKit theme that follows the site's light and dark theme, and a header button built on `ConnectButton.Custom` with our own buttons.
- Wallet providers mount in the studio layout only; the landing page ships none of the wallet code.
- `config/env.ts`: public environment validated with zod at startup (`NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID`).
- CI reads the WalletConnect project id from the repository variable of the same name.
- TanStack Query ESLint rules turned on.
- `@coinbase/cdp-sdk`, pulled in by wagmi's Base Account connector, imports optional `@x402/*` packages that Turbopack cannot leave unresolved. They are aliased to `stubs/optional-peer.mjs`, which throws if anything calls it; MonadStudio does not use x402 payments.

## Removed

- The static "Monad testnet" label in the studio header (the wallet button shows the network).

## Verification

- Tests for the wallet button: before mount, not connected, wrong network, connected.
- `pnpm preflight` passed. The production build prerenders `/studio`.
